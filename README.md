# ApexFlow

A web application for discovering and keeping track of upcoming motorsport trackdays.

## About

ApexFlow is a full-stack web application being developed as part of a Web Frameworks project.

The application allows motorsport enthusiasts to browse upcoming trackday events and save events they are interested in attending. User accounts and saved events are stored using MongoDB.

The project is being developed using the **MEAN stack**, following an MVC architecture.

## Features

* User registration and login
* Browse upcoming trackdays
* View trackday information such as:

  * Circuit
  * Date
  * Organiser
  * Price
  * Available spaces
* Save trackdays to a personal account
* View saved trackdays
* Responsive interface for desktop and mobile devices
* REST API for handling application data
* Optional weather information for trackday events
